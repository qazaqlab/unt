## 🚀 Негізгі мүмкіндіктер

1. **5 Ай / 20 Апта / 140 Күндік Анти-Выгорание бағдарламасы**:
   * Күніне 3 сағат: 50 минут Физика + 50 минут Математика + 40 минут Қазақстан тарихы + 20 минут Мат.сауаттылық.
   * Аптаның 6-күні — 130 балдық апталық сынама тест және қатемен жұмыс.
   * Аптаның 7-күні — Толық демалыс күні (выгораниеден қорғау).
2. **108 Ресми ҰТО-2026 тақырыбы**:
   * Физика (25 тақырып, 50 балл).
   * Математика (18 тақырып, 50 балл).
   * Қазақстан тарихы (55 тақырып, 20 балл — 5-11 сынып толық).
   * Математикалық сауаттылық (10 тақырып, 10 балл).
3. **238 Интерактивті Quizizz Тесттері**:
   * 159 тест: Қазақстан тарихы 5, 6, 7, 8–9, 10, 11 сыныптар (§1–60 параграфтар бойынша).
   * 34 тест: Физика (кинематикадан квантқа дейін және нағыз ҰБТ кешенді нұсқалары).
   * 26 тест: Математика (алгебрадан стереометрияға дейін және 105 сұрақтық база).
   * 19 тест: Математикалық сауаттылық (логика, пайыздар, жас, жұмыс, графиктер).
4. **🏆 Ачивкалар & Геймификация Жүйесі**:
   * 18 ерекше ачивка (Стриктер, Помодоро фокус минуттары, пәндік шеберлік, 130 балл грант).
   * Тәжірибе ұпайлары (XP) және 5 сатылы дәреже (Бастаушыдан ҰБТ Гроссмейстеріне дейін).
5. **🔄 24/7 Авто-сақтау және Кросс-девайс Синхрондау**:
   * Деректер `localStorage`-ке автоматты сақталады (интернетсіз де жұмыс істейді).
   * Телефон мен ноутбук арасында 1 батырмамен прогресті экспорттау/импорттау.

## 🌐 GitHub Pages немесе Vercel-ге орнату (1 минут)

### 1-әдіс: GitHub Pages арқылы тегін онлайн сайт ашу
1. [GitHub.com](https://github.com) сайтында жаңа репозиторий ашыңыз (мысалы: `ubt-140-platform`).
2. Осы папкадағы барлық файлдарды сол репозиторийге жүктеңіз:
   ```bash
   git init
   git add .
   git commit -m "ҰБТ 130/130 платформасы: 108 тақырып + 238 Quizizz + Ачивкалар"
   git branch -M main
   git remote add origin https://github.com/<сіздің-логин>/ubt-140-platform.git
   git push -u origin main
   ```
3. Репозиторийдің **Settings → Pages** бөліміне өтіп, **Branch: main / Root (/)** таңдап, **Save** басыңыз.
4. 1 минутта сіздің жеке сайтыңыз дайын болады: `https://<сіздің-логин>.github.io/ubt-140-platform/`

### 2-әдіс: Vercel арқылы орнату
1. [Vercel.com](https://vercel.com) сайтына кіріп, **Add New Project** басыңыз.
2. Жоғарыдағы GitHub репозиторийін таңдаңыз.
3. **Deploy** батырмасын басыңыз — 30 секундта `https://<атауы>.vercel.app` дайын болады!
